# E-Commerce Software Testing

A practical manual QA project demonstrating software testing skills through functional testing, test case design, test execution, and defect reporting.

## Project Brief

This project demonstrates the manual software testing process for an e-commerce application, including test planning, scenario identification, test case design, test execution, and defect reporting.

## Testing Scope

- Functional Testing
- UI Testing
- Positive Testing
- Negative Testing
- Validation Testing
- Regression Testing

## Testing Tools

- GitHub
- Microsoft Excel
- Google Docs

## Test Artifacts

- Test Plan
- Test Scenarios
- Test Cases with Execution Results
- Defect Report

## Conclusion

Functional testing was performed based on the defined test scenarios and test cases. Test execution results were documented, and identified defects were recorded in the Defect Report. This project demonstrates the manual QA testing process from test planning through test execution and defect reporting.
