# Demoblaze E-Commerce Website - Test Plan


## 1. Objective

The objective is to test the Demoblaze e-commerce website and make sure its main features work correctly.


## 2. Features to Test

- User Signup
- User Login
- User Logout
- Product Categories
- Product Details
- Add Product to Cart
- Remove Product from Cart
- Shopping Cart
- Place Order


## 3. Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing


## 4. Test Environment

- Website: https://www.demoblaze.com/
- Browser: Google Chrome
- Operating System: Windows


## 5. Testing Tools

- GitHub – Test documentation and project management
- Microsoft Excel – Test case design, test execution, and defect tracking


## 6. Test Deliverables

- Test Scenarios
- Test Cases
- Test Execution Results
- Bug Reports



## 7. Conclusion

The purpose of this project is to test the main functionality of the Demoblaze e-commerce website and identify any defects found during testing.
